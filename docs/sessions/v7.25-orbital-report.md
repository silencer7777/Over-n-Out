# V7.25 — MERIDIAN ORBITAL, the space map (Job 2 §4) — slice report

**Status: shipped and live-verified (see footer/BUILD_NO check in the run log).**

## What landed

A fifth map, original to Over n' Out (§5): **MERIDIAN ORBITAL** — a
docking-station deck in orbit, built through the standard map pipeline
(data module → layout builder → solo dressing → lighting profile →
registry), playable solo (level picker) and online (map registry).

- `js/worlddata-orbital.js` — the data module (contract-complete):
  bulwark rail ring at ±80 (top 2.2, over jump apex — the deck is
  sealed), a cargo spine with a pylon pedestal at centre, a **gantry
  overpass** (walkable deck at 2.85 over the east–west lane, 0.57-rise
  stairs both ends, lane beneath stays open), a **raised docking arm**
  NE (platform 1.15, zone A stands on it), a habitat ring W (drums +
  connector + stepped airlock porch), an observation dome SE (glass
  landmark, hard cover), solar wings S, two container lanes, 2
  explosive coolant cells (barrels), 44 seeded cargo pods (16 with
  colliders). Station gravity is standard — movement physics
  identical on every map.
- Zones: A DOCKING ARM (56, 1.15, −46), B CARGO SPINE (0, 0, 0 —
  the pylon pedestal is the fixture; the capture heart is the ring
  around it), C HABITAT YARD (−38, 0, 1). Assault: REACTOR CONSOLE
  (−49.5, 0, 1). Transmissions stand on the dock, the gantry deck,
  and the dome platform.
- `js/mapbuilders.js` — `buildOrbitalLayout` (panel/metal surface
  buckets, merged POIs: pylon, docked pod, crane, hab drums, solar
  wings; glass dome; gantry light strip; instanced pods).
  **13 static draw calls** (layout budget 40).
- `js/biomes.js` — solo dressing `buildOrbital`: hull blanket,
  docking mast, glass dome, solar wing, hab drum, 36 instanced pods
  (big ones block) — all colliders honest, tracked, never walkable.
- `js/lighting.js` — new `orbital` profile ONLY (the four existing
  profiles are byte-identical): hard orbital sunlight, near-black
  sky, stars 0.9, no clouds, fog colour == sky horizon (coherence
  rule), elevation 38° inside its new band [30, 46].
- `js/maps.js` + `index.html` — registry row + level-picker option.
  Assault online uses the documented pool-split spawn fallback
  (no per-map staging set — same as forest/snow/mars).
