## The tab set shipped

Five tabs, all from EXISTING sections — nothing invented,
nothing dropped:

- **PLAY** — mission select, mode goal line, level select,
  ONLINE panel, LOBBY CHAT, DEPLOY, GO LANDSCAPE.
- **LOADOUT** — the whole loadout block (classes, weapons,
  attachments, spec panel, camo, gear line).
- **RECORD** — Service Record (profile emblem line, emblem
  pickers, badges, daily reward claim).
- **SUPPLY** — the SUPPLY shop (tier packages + special

- **SETTINGS** — the existing options page (story
  transmission, all settings, controls reference, BACK).

Header (title, chips, message, after-action results, profile
line) stays above the panels on every tab; the tab bar sits
outside the pages, sticky at the top, so it is reachable from
SETTINGS too. The OPTIONS and STORY buttons remain as
shortcuts into the SETTINGS tab; BACK returns to the tab you
came from.

## How it was built (and the one merge/split)

The meta panel (Service Record + SUPPLY in one block) is the
one split: at boot, js/main.js MOVES the live DOM nodes into
panel wrappers — appendChild moves, never rebuilds — and the
meta panel splits at its SUPPLY label (that child and
everything after it moves into a new #shop-panel inside the
SUPPLY tab). Because nodes are moved rather than recreated,
every handler and render loop keeps working by construction:
daily claim, emblem pickers, package/offer pickers, shop
lines, lobby chat, online join, loadout pickers — all bound
by id, all ids preserved (mobile-check T15e asserts each one
still exists in the served HTML).

Tab state: the active panel is the only one rendered
(`display:none` otherwise), so page-main no longer scrolls
as a single column; only a tall panel scrolls, under the
sticky tab bar. The last tab persists in localStorage
('ono-menu-tab') and is restored on return; default is PLAY.
`showMenuPage()` delegates to the tabs, so all existing
callers (menu returns, pause flow) behave as before.

Never-regress rules held: this is navigation, not tiles —
the start-menu GRID stays removed; ADS, minimap,
scorestreak code untouched.

## Phone fit

The bar is a wrapping flex row (max-width 640px, never wider
than the screen), buttons are 44px-minimum thumb targets with
plain click/tap handlers — identical for mouse and touch, no
hover dependence. mobile-check T15 asserts the bar, all five
tabs, the machinery, the wrap/44px/panel CSS, and the
surviving section ids.
