## Root cause (code-verified this session, Atlas)

Prior de-blockify passes (U9, U12, V7.20) added rounded
overlays ON the hit-core boxes — but many overlays are
SMALLER than the cores they soften, so the flat box faces
still define the silhouette:

- Leg core box half-extents 0.105 × 0.125 (corner radius
  0.163). Shin cylinder r 0.080–0.100 and ankle taper
  r 0.068–0.082 sit **fully inside the box** — invisible.
  Thigh cylinder r 0.104–0.128 covers the sides only; the
  flat front/back faces and all four vertical corners of
  the box still show.
- Torso core 0.66 × 0.38 (corner 0.381). Ribcage cylinder
  radii 0.334 × 0.195 and waist sash 0.29 × 0.18 leave the
  corners and flat faces exposed.
- Head core 0.34 cube vs face sphere r 0.168 — the sphere
  is inside the box's half-width (0.17); the cube reads.
- Online puppets (js/online.js) are built from raw boxes
  throughout (torso, arms, head, legs) — the blockiest
  figures in the game.

Detail was added; a shell OVER the core never was. That is
what a rebuild means here.

## Scope (one pen: Coordinator/Atlas on geo+bots, Vega on online)

1. **RB1 — rounded-prism shell geometry (js/geo.js).**
   `roundedPrismGeometry(w, h, d, r, taper)`: a vertical
   prism whose XZ cross-section is a rectangle with rounded
   corners (4 arc segments per corner), smooth-shaded,
   optional top taper. ~60 tris. Owner: Atlas. Acceptance:
   exported, used by both figure builders, no new deps.
2. **RB2 — leg shells (js/bots.js buildBotLeg).** Thigh
   shell (0.28 × 0.32 cross-section, r 0.10) + shin shell
   (0.27 × 0.31, r 0.095) envelop the leg core with
   ~+0.02 m margin and rounded corners, tapered. The
   now-buried thigh/shin/ankle/boot-collar cylinders are
   REMOVED (they were inside the core, hence invisible).
   Knee pad, calf mass, shin guard, boot, holster stay —
   all verified proud of the shell. Hit-core line
   byte-identical (D9). Walk-cycle split untouched.
3. **RB3 — torso shells (buildBotTorso).** Chest shell
   (0.74 × 0.46, r 0.13) + abdomen shell (0.72 × 0.44,
   r 0.10) envelop the torso core; the buried ribcage and
   waist-sash cylinders are removed. Vest, pouches,
   straps, deltoids, arms, pack verified proud of the
   shells. Hit-core line byte-identical.
4. **RB4 — head shell (buildBotHead).** Face ellipsoid
   enlarged r 0.168 → 0.188 (20×14) so it actually
   envelops the head core's faces; visor, nose, ears, jaw
   guard verified still proud. Hit-core line byte-identical.
5. **RB5 — puppets (js/online.js buildPuppetMesh).** Torso
   and legs become rounded prisms, arms become tapered
   cylinders, head becomes a sphere with a cylindrical
   helmet; visor re-seated on the sphere. Same merged-mesh
   + leg-split structure, same draw calls.
6. **RB6 — pins + witness.** characters-check gains CH6
   (shell wiring in bots + online, geo export). Version
   witness V7.34: BUILD_NO, index tag/stamp, mobile-check
   T7 named re-pin. package.json stays 0.7.28 (smoke M6).

## Budgets / integrity (Odin veto)

- Per-bot draw calls: Δ0 (shells merge into the existing
  leg/torso meshes; buried parts removed). Per-bot tris:
  expected Δ negative-to-flat (shells ~60 tris each vs
  removed multi-segment cylinders) — measured before/after
  with tools/v6-metrics.mjs and reported, never assumed.
- Maps: sustained calls ≤165, tris ≤300k, shadow ≤200 —
  unchanged statics; per-bot change flows through the
  metrics formula and is reported.
- Hit/balance integrity: hit cores byte-identical (smoke
  D9), no weapon/AI/movement numbers touched.
- Anti-glitch: shells are visual-only, inside the existing
  hit volumes' neighbourhood (+0.02 m); no colliders,
  spawns, or reachability surfaces change.
- Security: no new surface; Lockdown posture re-verified
  by the gate run + Watch. Nothing in this slice touches
  net/, protocol, or logs.
