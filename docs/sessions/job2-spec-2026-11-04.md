## §2 (FIRST — priority #1 inside it) — GLITCH PASS + the Mars Domination C bug

### Owner report (logged verbatim, Brett, 2026-11-04 ~21:37 PT)

> "Mars map domination c you can't get to it fix that as well"

### Investigation (Coordinator, this run — evidence, not conjecture)

Solo play renders ONE world (Compound, `js/world.js`) dressed by
the selected biome (`applyBiome`); Domination zones in solo ALWAYS
come from `js/modes.js`. Picking "Mars" + Domination therefore
plays the Compound Relay Tower as point C. Probes run against the
real built world and the data modules (strict model: radius-0.55
body vs AABB blocking per the shipped `collide()` rule, step-up
0.6, floors = collider tops):

- Mars data zones (online sim set): A/B/C all reachable step-only,
  with and without rock colliders. The Mars data is NOT the fault.
- Compound zones: A and B reachable step-only. Zone C's disc is
  technically grazable from a 2 m strip, but **the zone centre
  (40, −54) is unreachable, and the Assault relay console
  (38.8, 4.6, −56) is unreachable by any route, step or jump.**
- ROOT CAUSE: the Relay Tower straddles the V4 ruin-line north
  wall (z −51..−49). The wall segment x[27, 51], top 5.4
  (`js/worlddata.js` SOLIDS; mirrored in `js/world.js` as
  `B(39, −50, 24, 2, 5.4)`) cuts straight across the tower's L1
  deck (top 2.3), severing the only route: ground stairs (south
  face) → L1 south strip → **[wall: 3.1 m rise from deck, jump
  apex 1.88 — impassable]** → L1 north deck → L2 stair run → L2
  console. From outside the perimeter there is no way up either
  (2.3 m sheer deck edge, no north stairs). The shipped
  reachability gates never modelled this: `reachability-maps`
  uses looser-than-physics constants and compound
  `reachability` pins constants, not zone coverage.

### Fix (owner: Coordinator; acceptance below)

Remove the wall segment across the tower span only: the tower
body (solid y 0..2.3 across the full footprint) already seals
the perimeter line at ground level, so no gap opens. Segment
x[27, 51] @ 5.4 becomes x[27, 33] @ 5.4 + x[47, 51] @ 5.4 in
`js/worlddata.js`, mirrored 1:1 in `js/world.js`
(`B(30, −50, 6, 2, 5.4)`, `B(49, −50, 4, 2, 5.4)`). Zone
coordinates, stairs, decks, and the assault route are untouched —
the tower now plays exactly as designed (and the tower reads as
built into the wall line, which suits it).
