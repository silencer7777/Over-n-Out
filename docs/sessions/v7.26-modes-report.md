# V7.26 — Five new modes (Job 2 §6) — slice report

**Status: shipped; live verification in the run log.**

## Correction of record

The game shipped with **four** modes, not five (Wave Defense, Team
Deathmatch, Domination, Relay Assault). No "Sniper Alley" exists in
the code. This slice masters the four and adds five — nine total.

## The five new modes (all original Over n' Out, §5)

| Mode | Rules in one line | Where it plays |
|---|---|---|
| **MOVING CLAIM** | One of the three Meridian points is live; capture + hold it to score; the claim jumps every 45 s; first to 150 | **Solo + online** (full sim stepper) |
| **LONE SIGNAL** | Free-for-all: you vs 5 hunters, no teams; first to 12 eliminations — a hunter's kills on you count for that hunter | Solo |
| **UPGRADE PROTOCOL** | Weapon ladder pistol → smg → shotgun → rifle → DMR; each kill climbs a rung (weapon forced, fresh mag, manual switching locked); a kill on the top rung wins; dying drops a rung | Solo |
| **RELAY RUN** | Fetch the relay core, run it to the marked drop point (A→B→C rotation); carrying disables sprint; dying drops the core where you fell; 3 deliveries in 6:00 wins | Solo |
| **LAST TRANSMISSION** | Wave Defense's sibling: waves hunt the Carrier relay ring; integrity drains 4%/s while a hostile stands in the ring unchallenged, regens 1.5%/s while you hold it; clear wave 8 with the signal alive to win | Solo |

## Engineering notes

- Mode data lives in `js/modes.js` as the single source (defs, goal /
  win / lose text, `objectiveText` cases, story briefings in
  `js/story.js`). Claim/Relay zone coordinates mirror Domination's,
  which MD5 already pins against worlddata; MD6 now pins the copies.
- Solo runtime hooks are in the existing funnels: `onBotKilled` /
  `onTeamBotKill` (kills), `playerDown` (redeploy rules per mode;
  LONE SIGNAL credits the actual hunter via a last-attacker hook in
  the bot fire callback), `tickModes` (claim rotation + capture,
  relay carry/drop/deliver + core visual, lastsignal integrity),
  `beginMatchSpawns` (rosters: team fill only for team modes;
  lastsignal joins the wave family), `switchWeapon` (ladder lock),
  and the input compositor (relay carry kills sprint).
- MOVING CLAIM online: `stepClaim` in `net/sim.js` mirrors the solo
  brain (per-map zones from the world's MODE_ZONES — it plays on
  Meridian Orbital's own points too), bots steer to the live point,
  rotation emits `claim_rotate`, snapshots carry zones + claimIdx +
  claimT, and the client guide pill points at the live claim.
- **Honest scope:** the other four are solo missions for now. Their
  defs carry `online: false`; the client says so in plain words when
  you try to take one online, and the server falls back to the
  default mode instead of booting a stepper-less room
  (`ONLINE_MODE_IDS`). Nothing pretends otherwise.
